# 产品范围

## 定位

HLaunch 是纯本地离线的 Windows 原生 Grid 快速启动器，核心体验是“可视化网格优先，搜索辅助”。它不是以插件式命令搜索为核心的 Flow Launcher、PowerToys Run 或 Raycast 克隆，也不作为其他程序的自动化或集成平台。HLaunch 自身不访问远端服务；打开 URL 时只把用户配置的目标交给 Windows Shell。

主要平台为 Windows 11，构建和发布目标为 x64、x86、ARM64；x86 是 32 位程序，可用于兼容的 Windows 环境，不代表存在 Windows 11 x86 系统。Windows 10 22H2 已于 2025-10-14 结束常规支持，Windows 10 仍仅尽力兼容，主要面向 22H2 ESU 或仍受支持的 LTSC 环境。Windows 7/8/8.1 和 ARM32 不支持。每种架构的编译、自动测试与真机证据分开记录，不能把交叉编译通过当作运行验证。此范围由 `ADR-0007-tagged-multiarch-release.md` 取代旧的仅 x64 决策。

## V1 必须具备

- Grid、Tab 分类、跨 Tab 搜索。
- 应用、普通文件、文件夹、URL 和 `.lnk` 条目。
- 拖入添加、网格内重排、条目编辑与删除。
- 全局快捷键唤起。
- 屏幕边缘或角落停留唤起，多显示器可用，全屏时默认抑制。
- 屏幕边缘唤起支持按前台可执行文件名配置黑名单和白名单；白名单优先。
- 图标提取与磁盘缓存。
- 固定内置深色视觉，并在高对比度下使用 Windows 系统色。
- 托盘、用户主动开启的开机启动、单实例。
- 默认使用 EXE 旁 `data`，无读写权限时回退 AppData；可迁移的相对路径。
- 普通启动与“以管理员身份运行”。
- Per-Monitor DPI Awareness V2。
- 配置校验、schema 版本标识、高版本只读保护和设置界面。跨版本迁移在首次定义 schema v2 时再设计。

## V1 不做

- 插件系统、脚本执行或可扩展命令框架。
- 面向外部程序的 CLI、API、浏览器扩展或其他控制接口。
- 主题编辑、主题目录、主题包、背景图、自定义字体和组件样式覆盖。
- 在线更新、联网检查、云同步、遥测或账号系统。
- WinUI 3、Qt、WebView、.NET 或 MSIX 运行时依赖。
- Named Pipe、`WM_COPYDATA` 或其他通用结构化 IPC；单实例只保留 HLaunch 自身实例之间的固定小命令协调。
- 边缘停留进度提示和崩溃转储。

## 默认行为

| 项目 | 默认值 |
| --- | --- |
| 全局快捷键 | 启用 |
| 快捷键 | `Alt+Space`；可配置，注册失败必须提示 |
| 快捷键行为 | Toggle |
| 边缘唤起 | 关闭，由用户主动启用 |
| 热区 | Left |
| 停留时间 | 180 ms |
| 边缘宽度 | 4 DIP |
| 角落尺寸 | 16 × 16 DIP |
| 采样间隔 | 30 ms |
| 冷却时间 | 100 ms |
| 多屏模式 | Desktop outer edge |
| 边缘触发行为 | Show only，不执行 Toggle |
| 全屏时边缘唤起 | 抑制 |
| 启动后隐藏 | 启用 |
| 失去焦点隐藏 | 启用 |
| 开机启动 | 禁用 |
| 主窗口视觉 | 固定内置深色 |

`Alt+Space` 是已确认的产品默认值，同时也是 Windows 活动窗口系统菜单的既有快捷键。HLaunch 必须实际检查 `RegisterHotKey` 的结果；注册失败时给出明确提示并允许用户重新绑定，不能静默改成其他组合或宣称快捷键已启用。

边缘唤起关闭时，热区、多屏模式、全屏抑制和进程名单等用户选择继续保存。停留时间、边缘宽度、角落尺寸、采样间隔和冷却时间是内部固定参数，不在设置界面开放；schema v1 中的同名字段仅为旧版本回退兼容而保留并写入固定值。

## 优先级

- **P0 / V1**：上述“必须具备”功能。
- **P1 / V1.x**：V1 发布后的增强必须由真实使用反馈驱动，不预留边缘停留进度或崩溃转储模块。
- 当前没有 P2 或 V2 功能路线图；x64、x86、ARM64 构建属于已确认的发布范围。

在线更新、外部控制和扩展系统均不作为后续版本候选。改变这一边界必须由用户重新明确决定，并用新 ADR 取代当前离线封闭范围；不得仅因技术上可实现而预留模块、协议或依赖。

## 非功能目标

以下是待测目标，不是当前事实：Release x64 尽量控制在 1–3 MB；空闲内存不高于 25 MB；热启动显示 P95 不高于 50 ms；5000 条目搜索不高于 20 ms。正确性、稳定性和可维护性优先于体积。
