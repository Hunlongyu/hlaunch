# ADR-0005：CLaunch 式主界面与原生子对话框

- 状态：已接受
- 日期：2026-08-26

## 背景

HLaunch 的目标用户已经熟悉 CLaunch。此前界面虽然满足竖向、无边框、底部搜索和贴底 Tab 等要求，但可见条目会随数量改变布局，添加卡片占用固定位置，子窗口又重复实现了一套自绘交互。这使主界面的密度、区域菜单和窗口生命周期与 CLaunch 差异较大，也增加了视觉与键盘处理的维护成本。

## 决定

- 主窗口继续使用 Direct2D/DirectWrite 自绘，默认尺寸为 394 × 594 DIP，Grid 默认为 5 列 × 8 行槽位，标题区高度为 16 DIP，Grid 与 Tab 间距为 8 DIP。空槽保持可见但不绘制“添加”卡片。
- 标题区提供主菜单、运行期窗口置顶和关闭按钮；关闭按钮只收起 Launcher，明确的“退出”保留在主菜单与托盘菜单。
- 未置顶时，焦点转移到其他进程后自动收起；HLaunch 自身的菜单、搜索窗、设置窗、文件选择器和属性窗不触发误收起。置顶时使用 Topmost 并阻止失焦收起，只影响当前进程生命周期，不写入配置。
- Grid 空槽双击或右键可快速注册；真实条目、空槽、Tab 和标题区分别显示与区域相关的原生上下文菜单。
- 设置、快速注册、条目属性和页面文本输入使用标准 Win32 `#32770` 对话框，并固定为 Windows 默认浅色原生样式。Launcher 的固定深色视觉、材质和透明度不传递给原生子对话框。
- 搜索继续使用与主窗口等宽、位于其下方的独立附属窗口，默认隐藏，显示时不改变 Grid 或 Tab 坐标。

## 影响

固定槽位使拖放、命中测试和视觉位置稳定，也更接近用户已有的肌肉记忆。原生对话框获得标准焦点、键盘和辅助功能，并保持统一浅色外观，不呈现 Launcher 的自绘视觉。
