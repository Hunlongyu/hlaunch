# 全局快捷键

当前实现状态（2026-08-29）：已实现 `RegisterHotKey`/`UnregisterHotKey` RAII 服务、默认 `Alt+Space` 到 Toggle 的 UI 线程消息流、`MOD_NOREPEAT`、结构化键值转换、安全重绑和冲突时保留旧绑定。原生设置窗可启用/禁用快捷键，组合 Alt/Ctrl/Shift/Win 与 Space、数字、字母或 F1–F24（保留键 F12 除外），并在不重启进程的情况下应用。按键下拉框固定按 `Space → 0–9 → A–Z → F键` 排列，每次展开后再次把顶部复位到 Space；列表使用固定可见高度和原生垂直滚动条，鼠标滚轮可以浏览其余项目。运行时注册成功后才原子保存配置；注册冲突、边缘服务失败或保存失败时恢复之前的有效绑定并给出就地错误。无参数启动在快捷键注册成功时默认隐藏；首次启动注册失败仍由可操作警告框反馈。

## 契约

- 使用 `RegisterHotKey`，V1 不使用 `WH_KEYBOARD_LL`。
- 全局快捷键默认启用，组合为 `Alt+Space`，行为为 Toggle。
- 配置保存结构化的 modifiers 与 virtual key；显示字符串只用于 UI，不作为唯一持久化格式。
- 启用或修改快捷键时先尝试注册，成功后再提交配置。
- 注册失败时必须保留上一个有效快捷键；设置窗在状态区说明冲突，首次运行尚无有效值时将快捷键标记为未注册并显示可操作警告。
- 不得在注册失败后静默替换 `Alt+Space` 或显示为已启用。
- 程序退出、禁用或重新绑定时必须 `UnregisterHotKey`。

## 消息流

`WM_HOTKEY` 只产生激活请求，不包含窗口定位和动画逻辑。快捷键从隐藏状态激活时必须重新读取当前鼠标位置，使 Launcher 中心跟随鼠标，并把最终矩形限制在鼠标所在显示器的工作区内；靠近屏幕边缘时允许窗口偏离鼠标中心以保持完整可见。

## 边界情况

- 组合被系统或其他程序占用。
- 修饰键左右键差异不持久化。
- 用户录入只有修饰键、无主键或受限组合。
- 远程桌面、提权窗口和不同完整性级别下快捷键行为可能不同。
- 重启 Explorer 不应影响注册；会话切换后需要运行验证。

## 验收

- 注册、重绑、禁用、退出清理均有测试或可重复手工步骤。
- 被占用组合不会覆盖有效配置，也不会导致启动失败。
- 连续按键只在 UI 线程串行执行 Toggle。

## 当前验证

- `ACT-HOTKEY-001.registration` 在 Windows 上覆盖默认映射、受限键拒绝、真实 `RegisterHotKey` 冲突、保留旧绑定、释放后重试、禁用和析构清理；设置窗口测试覆盖组合键输出、边缘开关联动、窗口复用、下拉列表垂直滚动样式，以及弹出列表收到 `WM_MOUSEWHEEL` 后确实移动顶部索引。自动测试不使用依赖当前交互桌面的 `SendInput`，物理按键投递由人工运行矩阵验证。
- Debug 应用运行验证覆盖默认隐藏和第二实例 Toggle 显示/隐藏；几何测试覆盖窗口中心跟随鼠标、负坐标显示器与工作区边缘约束。物理快捷键重复唤起后的鼠标跟随、远程桌面、会话切换和不同完整性级别仍需人工矩阵验证。
