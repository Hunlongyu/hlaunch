# 全局快捷键

当前实现状态（2026-08-26）：已实现 `RegisterHotKey`/`UnregisterHotKey` RAII 服务、默认 `Alt+Space` 到 Toggle 的 UI 线程消息流、`MOD_NOREPEAT`、结构化键值转换、安全重绑和冲突时保留旧绑定。无参数启动在快捷键注册成功时默认隐藏；注册失败或快捷键禁用且无显式启动命令时保持主窗可达。快捷键显示与重绑设置页尚未实现，首次注册失败暂由可操作警告框反馈。

## 契约

- 使用 `RegisterHotKey`，V1 不使用 `WH_KEYBOARD_LL`。
- 全局快捷键默认启用，组合为 `Alt+Space`，行为为 Toggle。
- 配置保存结构化的 modifiers 与 virtual key；显示字符串只用于 UI，不作为唯一持久化格式。
- 启用或修改快捷键时先尝试注册，成功后再提交配置。
- 注册失败时必须保留上一个有效快捷键；首次运行尚无有效值时，将快捷键标记为未注册，并在设置页给出可操作错误。
- 不得在注册失败后静默替换 `Alt+Space` 或显示为已启用。
- 程序退出、禁用或重新绑定时必须 `UnregisterHotKey`。

## 消息流

`WM_HOTKEY` 只产生激活请求，不包含窗口定位和动画逻辑。快捷键激活定位到当前鼠标所在显示器的工作区中心，最终矩形必须限制在工作区内。

## 边界情况

- 组合被系统或其他程序占用。
- 修饰键左右键差异不持久化。
- 用户录入只有修饰键、无主键或受限组合。
- 远程桌面、提权窗口和不同完整性级别下快捷键行为可能不同。
- 重启 Explorer 不应影响注册；会话切换后需要运行验证。

## 验收

- 注册、重绑、禁用、退出清理均有测试或可重复手工步骤。
- 被占用组合不会覆盖有效配置，也不会导致启动失败。
- 连续按键只在 UI 线程串行执行 Toggle。

## 当前验证

- `ACT-HOTKEY-001.registration` 在 Windows 上覆盖默认映射、受限键拒绝、`SendInput` 到真实 `WM_HOTKEY` 投递、冲突保留旧绑定、释放后重试、禁用和析构清理。
- Debug 应用运行验证覆盖默认隐藏、第二实例 Toggle 显示/隐藏，以及当前鼠标显示器工作区居中；物理键盘、远程桌面、会话切换和不同完整性级别仍需人工矩阵验证。
