# Launcher UI 与交互

> 尺寸契约更新（2026-08-27）：下文历史状态中的“固定 5 × 8”现表示默认值。主窗口已经支持八方向按完整行列量化缩放，当前行列数持久化到 `config.json`。

当前实现状态（2026-08-29）：已完成无系统标题栏的 Direct2D/DirectWrite Launcher、底部搜索窗、完整槽位 Grid 和贴底 Tab。主窗口在 Windows 11 使用较小的系统圆角；窗口支持 Solid、Mica、Acrylic、Tabbed 和 30%–100% 整体透明度，背景效果与透明度均可从双页签原生“设置”窗口的常规页修改并立即生效。主窗口固定使用内置深色视觉与 Windows 系统字体，不提供主题、背景图、自定义字体或组件样式编辑。高对比度时使用 Windows 系统色。量化行列缩放、Tab/Item 顶层跟随拖拽预览、Grid 精确槽位重排、跨 Tab 搜索、Shell 图标后台提取和 UI Automation Provider 均已接入。

图标后台线程优先读取数据根 `cache/icons` 中经过版本、身份、尺寸和校验和验证的预乘 BGRA 像素，未命中时重新提取并原子替换缓存。缓存身份包含目标、显式图标、请求像素尺寸及源文件时间/大小，最多保留 256 项或 64 MiB。UI 线程按“稳定条目 ID + 目标物理像素尺寸”保留最多 128 个内存变体；不同 DPI 屏幕的 32/40/48/56/64 px 等版本可以同时存在，异步结果只有在条目、源和尺寸均匹配时才进入当前变体。设备丢失只重建 Direct2D 位图，不丢弃已解码像素。

## 信息结构

Launcher 由紧凑标题区、当前 Tab 的固定槽位 Grid、贴底 Tab 和默认隐藏的附属搜索窗组成。视觉层级必须以 Grid 为主；搜索是过滤和跨分类查找入口，不应把默认界面变成命令列表。

标题区高度为 16 DIP；`HLaunch` 使用 13 DIP、常规字重和弱化文字色，不与 Grid 内容争夺视觉焦点。标题文字和三个字体图标共用相对标题栏几何中心向上 1 DIP 的视觉校正，以补偿 Segoe 字形可见重心偏低；校正只影响绘制范围，不改变点击、拖动和 UI Automation 边界。左侧主菜单、右侧置顶/取消置顶与关闭按钮统一优先使用 Windows 11 的 `Segoe Fluent Icons`，运行时找不到该字体族时回退到 Windows 10 自带的 `Segoe MDL2 Assets`；两套字体使用兼容字形 `E700`/`E718`/`E77A`/`E711`。菜单与关闭字形使用 14 DIP，轮廓面积天然更大的置顶/取消置顶字形单独使用 12 DIP，使三者视觉重量接近；三个按钮仍保持相同的 16 × 16 DIP 点击和无障碍边界。置顶与关闭按钮之间保留 4 DIP 空隙。主菜单、标题、未置顶图标和关闭图标默认统一使用弱化文字色；标题按钮悬浮或按住时不绘制背景，菜单与置顶图标自身变亮，关闭图标自身切换为警示色；置顶状态同时使用取消置顶字形和强调色，不只依赖颜色表达。

## Grid 与 Tab

- 鼠标悬浮在真实条目时不改变 Item 背景色，只显示 1 DIP 纯白 `#FFFFFF` 边框；键盘焦点同样使用 1 DIP 白色轮廓。拖拽落点继续使用 3 DIP 强调色，避免把普通悬浮与即将放置混淆。Item 描边中心必须向卡片内部缩进半个线宽，使第一行顶部以及其余三边都完整位于 Grid 裁切区内。Tab 普通背景为 `#252525`、悬浮背景为 `#414141`，所有 Tab 文字使用主文字色。主菜单、置顶和关闭按钮只改变图标颜色，不显示悬浮或按下背景。空槽不显示悬浮高亮，避免暗示单击可注册。键盘焦点轮廓与鼠标悬浮状态独立保留。
- 鼠标停留在真实条目 150 ms 后，标题区临时显示该条目的完整名称，并使用 Windows 原生 `tooltips_class32` Tooltip 再显示一次名称；Tooltip 位于当前 Item 底部 4 DIP，按 Item 水平中心对齐。Tooltip 不使用 `TTS_BALLOON`、自绘、应用自定义颜色或圆角，最终外观由当前 Windows 视觉样式决定。标题区宽度不足时可裁切，Tooltip 必须保留完整文本。鼠标移动到空槽、Tab、标题区或窗口外后，标题立即恢复为 `HLaunch` 并关闭 Tooltip。拖拽 Item 或 Tab 时不显示 Tooltip，避免遮挡落点。
- Grid Item 名称固定为单行居中显示，不自动换行；文字超过卡片可用宽度时在卡片边界直接裁切，不能挤占第二行或改变图标位置。
- Grid Item 图标固定显示为 32 × 32 DIP，而不是固定 32 个物理像素。目标像素尺寸按实际承载 HWND 的 Per-Monitor DPI 计算：100%/125%/150%/175%/200% 分别使用 32/40/48/56/64 px。显式 `.ico`、`.png` 由 WIC 直接解码；多帧图标依次选择精确尺寸、最小的较大尺寸、最大的较小尺寸。文件、文件夹、快捷方式和程序优先向 Windows Shell 请求接近目标尺寸的图像。Shell 直通 Alpha BGRA 与其他来源必须先转换为预乘 BGRA，再使用 WIC Fant 保持宽高比缩放一次，并在透明正方形画布中居中；输出逐像素满足 `B/G/R <= A`，完全透明像素的颜色通道为零。Direct2D 目标矩形对齐物理像素边界，避免第二次模糊采样。
- 每个条目有稳定 ID，不以显示名称或位置作为身份。
- Grid 重排必须保存顺序；跨 Tab 拖动必须保存目标 Tab 与位置。
- 当前鼠标拖拽只有超过系统拖拽阈值后才生效，避免破坏单击启动。同 Tab 放到卡片或空槽时保存最终 Grid 位置；放到其他 Tab 时以该 Tab 末尾作为明确目标位置。拖动真实条目期间显示包含源图标和名称的浮动卡片，卡片由独立、无激活、鼠标穿透的顶层工具窗口承载，中心随鼠标横纵坐标连续移动并可越过 Launcher 客户区边界；该顶层窗口独立响应 `WM_DPICHANGED`，跨越不同 DPI 屏幕时保持相同 DIP 尺寸、鼠标中心和对应物理像素图标。浮动卡片必须复用原位条目的表面色、普通边框、图标与名称，不增加悬浮色或强调边框。目标格或目标 Tab 的强调反馈继续保留。搜索结果状态下禁用重排，避免筛选顺序与持久顺序混淆。
- Tab 同样使用系统拖拽阈值区分单击与排序；拖动期间源 Tab 浮动预览使用与条目共享的独立顶层工具窗口，中心直接跟随鼠标横向与纵向移动，可越过 Launcher 客户区边界；浮动 Tab 必须保持源 Tab 的活动/非活动文字颜色及活动底线，不增加强调边框。Tab 栏对每个有效落点始终显示强调色插入竖线，拖回源位置也不能隐藏，竖线位置必须与松手后的最终索引一致。右键左移/右移保留为键盘或辅助入口，不是主要排序方式。
- Tab 当前支持新建、通过右键“重命名”直接修改名称、删除以及通过“排序页面”子菜单向左或向右移动，不使用含糊的“属性”入口。到达首尾边界时禁用无效方向；移动分类时保留分类稳定 ID、全部条目和活动状态，并提交后台保存。删除空 Tab 直接执行，不显示确认框；删除非空 Tab 前必须确认，确认后把条目移动到另一分类，不能静默丢失。
- 非空 Tab 的右键菜单可启动页面中的全部项目；空页面禁用该命令。每个项目仍独立经过相对路径解析、Shell 错误处理和 UAC 取消处理，单个失败不阻止继续尝试其余项目。
- 窗口尺寸、Grid 列数和间距均以 DIP 计算，并随 Per-Monitor DPI 变化重新布局。边缘缩放按一个完整条目行或列跳变，不允许持久化半格像素尺寸；默认 5 × 8，可配置范围为 3–20 列、3–20 行。
- 主界面按当前行列数绘制槽位，空槽不显示“添加”文字；双击 Grid 不绑定任何操作，添加项目只通过空槽右键菜单、`Insert` 等明确入口触发。通过空槽菜单添加并确认后的新条目必须保留触发注册的精确空槽位置，不能自动追加到末尾空位。空 Tab 不显示“暂无条目”等额外提示。
- 搜索没有匹配结果时保持 Grid 空白，不在 Grid 上覆盖结果数量、日志或提示文案。图标加载中和条目失效仍需提供非侵入式状态。
- Tab 区域高度固定为 30 DIP，背景色带从窗口左边缘连续贯穿到右边缘；Tab 之间无间隙、无圆角。当前 Tab 的底部高亮线固定使用 `#0D7FD9`、高度 4 DIP，并填满当前 Tab 宽度且绘制在窗口底部边界，不保留额外底部间距。Grid 最后一行底边与 Tab 顶部保持 8 DIP 垂直间距。高对比度模式下 Tab 与高亮线改用系统色。
- Tab 默认最小宽度为 64 DIP，名称单行显示且不压缩成竖排文字。可用宽度不足时只绘制一段连续分类并隐藏溢出项，不创建横向滚动条；鼠标滚轮和 `Tab`/`Shift+Tab` 仍在全部分类间循环，并自动移动可见区以保证活动分类始终可见。Tab 绘制、单击、悬浮、右键、拖拽和 UI Automation 均使用同一可见索引映射。
- 默认单屏容量为 40 项，实际容量等于当前列数乘行数；条目超过当前容量时不显示右侧分页位置条或垂直滚动条，`PageUp`/`PageDown` 仍移动一屏，键盘焦点移动到视口外时仍自动翻页。鼠标滚轮不滚动 Grid，而是在主界面任意区域切换分类。
- 增减行只改变单页可见容量，不修改 `gridSlot`；增加列保持每个条目的二维行列坐标。减少列时，仍在有效列内的条目保持原位，只有被裁掉列中的条目按原顺序从下一行开始就近向后溢出，不回填当前行或更早的历史空洞。

## 条目操作

条目编辑器至少覆盖名称、目标、可选参数、可选工作目录、图标、所属 Tab、普通/管理员启动方式。文件或目标不存在时允许用户修复或删除，不能令整个数据文件加载失败。

添加与编辑共用同一套原生 Win32 模态“项目编辑器”，只根据操作切换窗口标题、主按钮文案和初始值，避免两套窗口的字段与布局漂移。编辑器按客户区尺寸布局，左右各保留 20 DIP 边距；使用紧凑的固定标签列、8 DIP 水平间隔和一致的垂直节奏，统一覆盖名称、类型、目标、参数、工作目录、图标、所属分类和管理员启动。目标、工作目录和图标均提供浏览按钮，图标选择器支持 `.ico`、`.png`、`.svg`、`.exe` 和 `.dll`。SVG 使用 Windows 原生 Direct2D SVG 文档解析并按目标 DPI 渲染到透明预乘 BGRA 位图，根视口归一到图标画布并保留 `viewBox` 纵横比；无效、空白或超过 8 MiB 的 SVG 安全失败并回退目标图标。工作目录是可选的进程起始文件夹，仅供依赖相对路径的批处理、命令行工具或旧程序使用，普通应用和 URL 通常留空。新增时名称可留空并从目标自动推导，图标留空时使用目标的系统图标；参数输入区每行表示一个逻辑参数。从空槽菜单选择“注册项目”或按 `Insert` 添加；双击 Grid 不触发任何操作。焦点位于真实条目时按 `F2`，或从条目菜单选择“属性”。保存成功后立即更新内存文档、Grid、活动 Tab、焦点和搜索索引，再把完整快照提交后台保存；编辑时保留稳定 ID、`launchCount` 和 `lastLaunchedAt`。首次没有 `items.json` 时提供空的“默认”分类。

右键条目菜单按“启动 / 文件与复制 / 布局与分类 / 删除与属性”分组，显示打开、以管理员身份运行、打开文件所在位置、复制名称/目标/完整命令、插入、移动到分类、删除和属性。上述动作均已接入：管理员启动只覆盖本次启动，不修改条目属性；打开所在位置使用 Explorer 选中目标，URL 条目不提供该动作；完整命令按 Windows 参数引用规则生成。移动分类子菜单列出真实分类、禁用并标记当前位置，选择其他分类时把条目追加到目标分类末尾、切换到目标分类并提交后台保存。条目菜单不提供锁定按钮或行/列操作；行列仍只通过窗口边缘按完整 Grid 单位缩放。空槽菜单只提供注册项目和插入按钮，不提供子菜单或删除空按钮。空槽、Tab 和标题区使用各自菜单，不能复用条目菜单冒充区域操作。键盘 `Delete` 直接进入删除确认。确认框必须以“否”为默认按钮，取消时不得提交文档变更。删除成功后选择原位置的下一项；若删除末项则选择前一项。搜索状态下删除命中的真实条目后保持当前查询并重建结果。

Shell 成功接受启动后，按稳定 ID 增加 `launchCount`、写入 UTC `lastLaunchedAt`、刷新搜索排序并后台保存；启动失败或 UAC 取消不计数。

拖放输入至少支持文件、文件夹、`.exe`、`.lnk` 和可解析 URL。批量拖入应保持来源顺序。目标、参数、工作目录和提权设置均相同才是完全重复；此时提示并默认跳过，任一启动属性不同则允许并存。

## 搜索

- 搜索框默认隐藏；直接输入可见字符或按 `Ctrl+F` 进入搜索状态，`--show-search` 仅用于诊断预览。查询非空时第一次 `Esc` 清空，查询为空时再次 `Esc` 隐藏 Launcher。
- 搜索使用主窗口拥有的独立无边框附属窗，显示在主窗口下方；显示或隐藏时不参与主窗口布局，Grid 和 Tab 坐标必须保持不变。
- 附属搜索窗与主窗口左右边界对齐并保持相同宽度。当前 394 DIP 主窗口下，附属窗同为 394 DIP、间隔 6 DIP；内部输入区域保留左右各 8 DIP 间距。
- 搜索输入使用无边框原生 `EDIT` 保留文本选择、IME 和辅助功能语义。普通模式强制使用 `#303030` 实心画刷，并把原生输入子窗口设为 255 全不透明的分层子窗口，避免 GDI 在父窗口预乘 Alpha 表面上只更新 RGB 后被 DWM 合成为浅灰色；输入背景与搜索图标所在表面的最终屏幕颜色一致。文字与插入光标在垂直方向居中，鼠标进入实际编辑区域时显示系统 I-beam 光标。高对比度模式恢复 Windows 系统输入背景，不能为了固定颜色损害可读性。
- 附属窗随主窗口移动，并随主窗口隐藏；不得产生独立任务栏按钮或脱离所有者的 Z 序。
- 默认在全部 Tab 搜索；搜索结果卡片只显示项目名称，不显示来源 Tab 名称。搜索结果模型仍保留来源 Tab 与条目索引，以保证启动、编辑、删除和定位作用于正确的真实条目。
- 查询产生结果后默认选中排序第一项，直接按 `Enter` 启动该项；搜索输入框保持文字焦点时，方向键仍按当前 Grid 行列移动结果选中项，跨出当前视口时自动分页并保持选中项可见。查询变化后根据新排序重新选中第一项；无结果时不保留虚假选中。
- 匹配优先级：Exact > Prefix > Substring > Fuzzy。
- 同级结果可以结合使用频次和最近使用时间，最终使用稳定 ID 作为 tie-breaker。
- 查询在 5000 条目内不得阻塞 UI；索引更新与数据变更一致。
- V1 使用 Unicode 不区分大小写比较，不承诺拼音或变音符号折叠；不得暗示未实现能力。
- 搜索保留完整排序结果并复用 Grid 的键盘分页，不截断为首屏 40 项，也不显示右侧分页位置条。查询非空时滚轮不切换分类，避免搜索结果与活动分类语义冲突。

## 键盘与焦点

- Launcher 显示后，用户能用键盘完成搜索、Grid 导航、Tab 切换、启动和关闭。
- Launcher 普通浏览状态显示或分类切换后没有选中项，也不绘制隐式的首项焦点；搜索查询产生结果时例外，默认选中排序第一项并允许直接按 `Enter` 启动。普通浏览状态首次按任一方向键选择当前视口第一项；`Home`/`End` 选择当前可见范围首项/末项，`PageUp`/`PageDown` 选择并移动一屏。之后方向键在普通 Grid 和搜索结果 Grid 中移动焦点，并在跨页时自动调整可见视口；到达行边界时不循环，不完整末行向下移动时停在该行最后一个真实条目。
- `Tab`/`Shift+Tab` 循环切换分类并清除条目选中；`Enter`、`F2` 和 `Delete` 在没有键盘选中项时不执行条目操作。`Insert` 添加条目，`Ctrl+O` 打开设置，`Ctrl+Space` 切换窗口置顶，`Esc` 隐藏 Launcher。空槽不进入 Grid 焦点，键盘通过 `Insert` 提供等价操作；`Alt+F4` 明确退出进程。
- 搜索非空时 `Esc` 先清空；搜索为空时 `Esc` 隐藏 Launcher。
- 焦点不能因异步图标完成或动画重建而丢失。
- 未置顶时，焦点转移到其他进程后自动收起，Item 启动成功后也自动收起。置顶状态把窗口加入 Topmost 层，并在失焦或启动 Item 后继续保持显示；`Esc`、关闭按钮、托盘 Toggle、`--hide` 等明确隐藏操作仍可收起。置顶只在本次进程内有效，不写入配置。
- `Hide on focus lost` 不能在原生设置、注册、属性、上下文菜单、附属搜索窗或文件选择器打开时误隐藏主交互。

## 窗口拖拽

- 无边框窗口中，真实 Item、Tab 区域、主菜单按钮、置顶按钮和关闭按钮保留各自交互，不能触发窗口拖拽。
- 其余主窗口客户区几乎都可拖动窗口，包括标题区、置顶与关闭按钮之间的 4 DIP 空隙、窗口外边距、Grid 空槽、Grid 单元格间隙以及 Grid/Tab 之间的间隙。
- 空 Grid 槽按下后使用系统拖拽阈值区分点击与窗口移动：未超过阈值时不执行左键动作，仅保留右键菜单；超过阈值后转入原生窗口移动。Grid 间隙没有点击或双击动作，可直接作为标题拖动区。
- 命中区域使用与渲染相同的 DIP 布局结果，缩放或调整窗口尺寸后不能依赖硬编码像素。
- 最外侧 6 DIP 优先作为无边框缩放命中区，四角可同时改变行列；拖动左/上边时固定相对边。`WM_SIZING` 阶段只产生完整行列尺寸，并从拖动开始时的文档快照实时预览目标列布局；结束缩放后才统一保存配置和最终列重排，取消或拉回原尺寸不得累积移动条目。

## 可访问性

Direct2D 自绘控件必须提供 UI Automation 信息：名称、角色、状态、焦点、可调用动作和 Grid 位置。颜色不能是唯一状态提示；焦点指示必须可见；文本和交互尺寸应考虑系统缩放与高对比度。

## 动画

支持 Fade、轻微 Slide 或 None。尊重系统“减少动画”偏好。动画不能延迟输入、命中测试或辅助功能树更新。

## 透明与系统材质

- 默认背景材质为 Acrylic；诊断启动参数为 `--backdrop=solid|mica|acrylic|tabbed`。
- `config.json` 可持久化背景材质和 30%–100% 的整体不透明度；设置窗口提供“纯色（Solid）”“云母（Mica）”“亚克力磨砂（Acrylic）”“标签式云母（Tabbed）”四种背景效果，以及滑块与数字输入修改整体不透明度。应用后主窗口与搜索窗同步刷新并后台保存；显式指定 100 时会移除分层窗口样式并恢复完全不透明。
- `--backdrop` 与 `--opacity=30..100` 是本次启动的诊断覆盖，不会自动写回配置；低于 30 会使内容难以辨认，因此拒绝。
- 系统材质、窗口整体透明度、固定内容表面 alpha 是三个独立层级，不能用一个“透明”布尔值混合表达。
- 普通模式的内置主窗口背景基色为 `#373737`，Tab 表面基色为 `#252525`，Grid Item 表面基色为 `#515151`；高对比度模式继续使用 Windows 系统色。
- 非 Solid 模式必须用预乘 alpha 渲染目标并把客户区清成全透明；随后叠加主窗口背景基色，卡片、搜索框等内容表面再独立叠加固定内置颜色，因此系统材质下的最终屏幕像素会与背板混合。
- Windows 不支持请求的 DWM 材质时回退到系统模糊；模糊也不可用时仍显示半透明深色表面，不能导致窗口创建失败。
- 高对比度模式下自动使用系统色、Solid 和 100% 不透明度。
