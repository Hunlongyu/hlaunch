# Launcher UI 与交互

当前实现状态（2026-08-26）：已完成无系统标题栏的竖向 Direct2D/DirectWrite 界面，包含紧凑自绘标题区、默认隐藏的底部附属搜索窗、5 列紧凑 Grid 和贴底 Tab，Grid 名称居中。窗口默认请求 Acrylic 背景，支持 Solid、Mica、Acrylic、Tabbed 四种系统背景与 30%–100% 整体透明度；搜索框和卡片使用独立半透明表面，文字保持不透明。Tab 和条目来自 `items.json`，支持鼠标切换/启动、滚轮逐行浏览，以及方向键、Home/End、PageUp/PageDown、Tab/Shift+Tab、Enter、Esc 和可见条目焦点，空文档/空 Tab 有明确状态。直接输入字符或按 `Ctrl+F` 可打开搜索，结果覆盖全部 Tab 并支持继续输入、退格、粘贴、滚轮/分页、方向/Home/End、Enter 和 Esc。原生单窗口编辑器已支持添加与编辑条目、跨 Tab 移动和后台持久化；`Delete` 与右键菜单可删除当前条目，确认框默认“否”，取消不修改数据，成功后焦点落到相邻条目并同步搜索索引。OLE 拖放已支持文件、文件夹、`.exe`、`.lnk` 与可解析 URL，来源解析在后台执行，批量顺序保留；落在 Tab 上时导入该 Tab，否则导入当前 Tab。完全重复项只比较目标、参数、工作目录和提权设置，并以“跳过”为默认选择。当前 420 × 640 DIP、5 列与单屏 25 项仍是暂定值，不关闭 `open-decisions.md` 中对最终尺寸与容量的决策。当前图标仅以条目名称首字符和类型色块占位；Grid 重排和真实图标尚未实现。

## 信息结构

Launcher 由搜索框、当前 Tab 的 Grid、Tab 切换区和必要的轻量状态提示组成。视觉层级必须以 Grid 为主；搜索是过滤和跨分类查找入口，不应把默认界面变成命令列表。

## Grid 与 Tab

- 每个条目有稳定 ID，不以显示名称或位置作为身份。
- Grid 重排必须保存顺序；跨 Tab 拖动必须保存目标 Tab 与位置。
- Tab 支持新建、重命名、排序和删除。删除非空 Tab 前必须确认条目去向。
- 窗口尺寸、Grid 列数和间距均以 DIP 计算，并随 Per-Monitor DPI 变化重新布局。
- 空 Tab、无搜索结果、图标加载中和条目失效都要有明确状态。
- Tab 区域贴住客户区底部，高亮线绘制在窗口底部边界，不保留额外底部间距。
- Grid 容量按当前 DIP 可见行列计算，最多显示 25 项；超出后滚轮每格移动一行，右侧显示位置指示，`PageUp`/`PageDown` 移动一屏。

## 条目操作

条目编辑器至少覆盖名称、目标、可选参数、可选工作目录、图标、所属 Tab、普通/管理员启动方式。文件或目标不存在时允许用户修复或删除，不能令整个数据文件加载失败。

当前使用原生 Win32 Controls 的模态单窗口编辑器。点击 Grid 尾部“添加”卡片或按 `Insert` 添加；焦点位于真实条目时按 `F2`，或从条目右键菜单选择“编辑”。参数输入区每行表示一个逻辑参数。保存成功后立即更新内存文档、Grid、活动 Tab、焦点和搜索索引，再把完整快照提交后台保存；编辑时保留稳定 ID、`launchCount` 和 `lastLaunchedAt`。首次没有 `items.json` 时提供空的“常用”分类，使添加入口可直接使用。

右键条目显示“编辑 / 删除”菜单；键盘 `Delete` 直接进入删除确认。确认框必须以“否”为默认按钮，取消时不得提交文档变更。删除成功后选择原位置的下一项；若删除末项则选择前一项，空 Tab 回到添加入口。搜索状态下删除命中的真实条目后保持当前查询并重建结果。

拖放输入至少支持文件、文件夹、`.exe`、`.lnk` 和可解析 URL。批量拖入应保持来源顺序。目标、参数、工作目录和提权设置均相同才是完全重复；此时提示并默认跳过，任一启动属性不同则允许并存。

## 搜索

- 搜索框默认隐藏；直接输入可见字符或按 `Ctrl+F` 进入搜索状态，`--show-search` 仅用于诊断预览。查询非空时第一次 `Esc` 清空，查询为空时再次 `Esc` 隐藏 Launcher。
- 搜索使用主窗口拥有的独立无边框附属窗，显示在主窗口下方；显示或隐藏时不参与主窗口布局，Grid 和 Tab 坐标必须保持不变。
- 附属搜索窗与主窗口左右边界对齐并保持相同宽度。当前 420 DIP 主窗口下，附属窗同为 420 DIP、间隔 6 DIP；内部输入区域保留左右各 8 DIP 间距。
- 附属窗随主窗口移动，并随主窗口隐藏；不得产生独立任务栏按钮或脱离所有者的 Z 序。
- 默认在全部 Tab 搜索；UI 明确显示结果来源。
- 匹配优先级：Exact > Prefix > Substring > Fuzzy。
- 同级结果可以结合使用频次和最近使用时间，最终使用稳定 ID 作为 tie-breaker。
- 查询在 5000 条目内不得阻塞 UI；索引更新与数据变更一致。
- V1 使用 Unicode 不区分大小写比较，不承诺拼音或变音符号折叠；不得暗示未实现能力。
- 搜索保留完整排序结果，并复用 Grid 的滚轮、位置指示与键盘分页，不截断为首屏 25 项。

## 键盘与焦点

- Launcher 显示后，用户能用键盘完成搜索、Grid 导航、Tab 切换、启动和关闭。
- 当前 Grid 使用方向键移动焦点并在跨页时自动调整可见视口，`Home`/`End` 跳到当前可见范围首项/末项，`PageUp`/`PageDown` 移动一屏；到达行边界时不循环，不完整末行向下移动时停在该行最后一个真实条目。
- `Tab`/`Shift+Tab` 循环切换分类并把条目焦点重置到首项，`Enter` 启动当前真实条目，`Insert` 添加条目，`F2` 编辑当前真实条目，`Esc` 隐藏 Launcher。“添加”卡片不进入 Grid 焦点，键盘通过 `Insert` 提供等价操作。
- 搜索非空时 `Esc` 先清空；搜索为空时 `Esc` 隐藏 Launcher。
- 焦点不能因异步图标完成或动画重建而丢失。
- `Hide on focus lost` 不能在模态编辑器、上下文菜单或文件选择器打开时误隐藏主交互。

## 窗口拖拽

- 无边框窗口中，搜索框、整个 Grid 矩形、Tab 区域和关闭按钮保留客户区命中，不能触发窗口拖拽。
- 其余客户区均可拖动窗口，包括标题区、窗口外边距和搜索/Grid/Tab 之间的间隙。
- Grid 的空白单元格仍属于 Grid 交互区域，避免未来框选、拖放和上下文菜单与窗口移动冲突。
- 命中区域使用与渲染相同的 DIP 布局结果，缩放或调整窗口尺寸后不能依赖硬编码像素。

## 可访问性

Direct2D 自绘控件必须提供 UI Automation 信息：名称、角色、状态、焦点、可调用动作和 Grid 位置。颜色不能是唯一状态提示；焦点指示必须可见；文本和交互尺寸应考虑系统缩放与高对比度。

## 动画

支持 Fade、轻微 Slide 或 None。尊重系统“减少动画”偏好。动画不能延迟输入、命中测试或辅助功能树更新。

## 透明与系统材质

- 默认背景材质为 Acrylic；诊断启动参数为 `--backdrop=solid|mica|acrylic|tabbed`。
- `--opacity=30..100` 控制整个顶层窗口透明度，默认 100；低于 30 会使内容难以辨认，因此拒绝。
- 系统材质、窗口整体透明度、主题表面 alpha 是三个独立层级，不能用一个“透明”布尔值混合表达。
- Windows 不支持请求的 DWM 材质时回退到系统模糊；模糊也不可用时仍显示半透明深色表面，不能导致窗口创建失败。
- 高对比度模式下必须关闭妨碍可读性的透明材质；该自动切换尚未实现，参见 `accessibility.md`。
