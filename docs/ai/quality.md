# 质量、安全与验证

## 证据等级

必须区分：静态检查、编译、单元测试、集成测试、运行验证、性能测量和多设备/多显示器验证。完成较低等级不能宣称较高等级已通过。

当前验证证据（2026-08-27）：MSVC x64 Debug 的 15 个 CTest 目标全部通过，覆盖依赖、数据编解码与存储、日志、搜索、条目添加/编辑/删除/重排、Shell/WIC 图标提取与后台回调、OLE 拖放、窗口与输入、快捷键、边缘唤起、当前用户开机启动、托盘和 Shell 启动。Launcher 窗口集成测试已验证 `Insert` 添加、`F2` 编辑、`Delete` 取消与确认、相邻焦点、全部编辑字段、同 Tab 鼠标重排、跨 Tab 拖动、边缘高级设置、开机启动设置和稳定 ID；Core 测试覆盖最终索引语义、跨 Tab 精确位置及无效移动不修改文档。开机启动测试覆盖含空格 EXE 路径引用、显式便携参数、HKCU 测试子键启用/查询/禁用和无关值保护。图标测试验证真实 EXE 的预乘 BGRA 尺寸、可见 alpha 与后台请求身份；OLE 数据对象测试验证 `CF_HDROP` 顺序、URL 文本、复制效果与格式拒绝，解析器测试验证文件、文件夹、`.exe`、`.lnk`、URL 和受拒 scheme；存储测试已验证后台快照合并与退出刷新。

既有运行证据还覆盖双实例转发、快捷键 Toggle、边缘 Show-only、托盘 Toggle、搜索附属窗对齐、Grid 分页、四种 DWM 材质属性和仅系统 DLL 的 Release 依赖。物理快捷键、多显示器完整矩阵、Explorer 重启、UI Automation、Explorer/浏览器真实鼠标拖放、高对比度、UAC 取消和失效目标矩阵仍未完成，不能宣称已验证。

## 单元测试

- Hot Zone：八方向、RECT 排他边界、负坐标、DIP 转像素、角落优先。
- Dwell：进入、离开、切换热区、抑制、冷却、时钟跳变和关闭竞态。
- Search：匹配优先级、稳定排序、Unicode、空查询和 5000 条目。
- Config：默认值、范围、未知/缺失字段、损坏文件、版本迁移和高版本保护。
- Path：便携根、相对路径、跨盘、环境变量和重解析点。
- Theme：缺失 token、坏图片、超限资源、路径逃逸和默认回退。
- Grid：排序、跨 Tab 移动、删除 Tab 和稳定 ID。

- Windows 11 x64 是发布阻断矩阵；Windows 10 x64 在可取得的 22H2 ESU 或仍受支持的 LTSC 环境做尽力兼容验证并单独标注，不与正式支持混报。

## 性能测量

- 空闲 CPU、内存、热启动显示 P95 和 5000 条目搜索延迟只在优化构建中测量。
- 边缘采样基准至少持续数分钟，并同时记录采样间隔、显示器数量和全屏检测策略。
- 图标首载与暖缓存分开报告。
- 目标值见 `product-scope.md`；超标应先定位瓶颈，不通过降低正确性掩盖。

## 日志与崩溃

当前轻量日志基础设施支持 TRACE、DEBUG、INFO、WARN、ERROR；标准模式写入 `%LOCALAPPDATA%\HLaunch\logs`，便携模式写入 `data\logs`。应用已接入启动、数据加载、窗口创建、快捷键、边缘服务、托盘、激活、条目启动结果和退出事件，并安装顶层异常过滤器记录异常码、指令地址与线程号。默认不记录用户文件内容、条目名称、目标、参数、搜索词或其他敏感内容。

默认保留最多 5 个日志文件，每个 2 MiB，并删除超过 7 天的文件；三个条件任一达到即可清理。诊断日志的配置关闭开关与设置 UI 尚未实现，不能把规划中的“可关闭”描述为当前能力。

P1 可用 `MiniDumpWriteDump` 生成本地崩溃转储。转储可能包含敏感内存，必须由用户主动提供，不自动上传。

## 安全

- 主题永不执行代码，资源访问受主题根目录约束。
- 不通过 Shell 拼接执行不可信命令；启动目标与参数分离。
- JSON 输入设大小与数量限制，所有整数做范围检查。
- IPC 不信任窗口消息中的指针；未来 Named Pipe 需要限制到当前用户。
- 更新功能若实现，必须使用 HTTPS、校验发布签名或强完整性元数据，并防止降级。
- 日志、缓存和备份遵循最小数据原则。

## 发布门槛

V1 发布前至少需要：干净 x64 Release 构建、全部自动测试通过、支持矩阵的关键运行场景通过、可访问性验证、依赖许可证清单、无额外运行时 DLL、配置升级/回退演练以及性能结果记录。证据按 `requirements.md` 的 ID 归档。
